Arcade-Shooter

DeltaBlade ist ein Arcade-Shooter. Du fliegst unten, die Gegner kommen in Wellen: normal, gemischt, Rang, Bonus, zwischendurch Kamikaze. Alle 25 Wellen ein Boss. Die Extra-Zeit läuft mit; bei null kommt ein UFO.

Waffen, Münzen, Scoop und Schild gibt’s als Drops. Eine Welle ohne Treffer ist eine Combo. Eine ganze Bonusrunde ohne Treffer gibt 20.000 Punkte. Sechs Rangmarker = ein Rang höher.

Highscores speichert das Spiel bei dir. Zusätzlich landen sie hier in der Liste.

Steuerung: Pfeile oder WASD, schießen mit Leertaste oder X

macOS Windows Linux AppImage

macOS: DMG öffnen, dann Installieren.command. Wenn macOS das Spiel blockiert (kein Entwicklerzertifikat): Systemeinstellungen → Datenschutz & Sicherheit, ganz unten „Trotzdem öffnen“. Oder Rechtsklick auf die App → Öffnen. Steht da „beschädigt“, im Terminal: xattr -cr auf die DMG bzw. auf /Applications/DeltaBlade.app.
